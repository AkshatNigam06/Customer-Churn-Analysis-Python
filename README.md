# Customer Churn Analysis using Python

Customer Churn Analysis project using Python to explore customer behavior, identify churn patterns, and understand factors influencing customer retention.

## 📌 Project Overview

Customer churn refers to customers discontinuing a service. This project analyzes customer churn patterns based on different customer attributes and identifies factors associated with higher churn rates.

The analysis focuses on:

- Contract Type
- Payment Method
- Customer Tenure
- Internet Service
- Senior Citizen Status

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

| File | Description |

## 🔍 Analysis Performed

The project analyzes churn percentages across different customer segments using data analysis and visualizations.

### Contract Type
Customers with month-to-month contracts show a higher churn rate compared with customers having one-year and two-year contracts.

### Payment Method
Customers using electronic checks show a higher churn percentage compared with other payment methods.

### Customer Tenure
Customers with shorter tenure show higher churn, while churn decreases as customer tenure increases.

### Internet Service
Churn patterns were analyzed across different internet service types.

### Senior Citizen Status
Churn percentages were compared between senior citizens and non-senior customers.

## 📊 Key Insights

- Month-to-month contract customers have a **42% churn rate**.
- One-year contract customers have an **11% churn rate**.
- Two-year contract customers have a **3% churn rate**.
- Electronic-check users have a **45% churn rate**.
- Customers with less than one year of tenure have a **50% churn rate**.
- Customers with 1–3 years of tenure have a **35% churn rate**.
- Customers with more than 3 years of tenure have a **15% churn rate**.
- Fiber Optic customers show a **30% churn rate**.
- DSL customers show a **20% churn rate**.
- Senior citizens show a **41% churn rate**, compared with **26%** for non-senior customers.

## 💡 Business Recommendations

Based on the analysis:

- Encourage customers to move toward long-term contracts.
- Investigate issues associated with electronic-check payments.
- Focus customer-retention efforts on customers in their first year.
- Develop targeted retention strategies for customer segments with higher churn.

## 📈 Project Outcome

The analysis helps identify customer segments associated with higher churn and provides insights that can support customer-retention strategies.
